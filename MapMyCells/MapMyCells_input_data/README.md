# MapMyCells_input_data

This folder contains the input files generated for the MapMyCells workflow (Allen Institute; RRID:SCR_024672). It includes the raw count matrix of the annotated zebrafish CA dataset with
cluster annotations appended to the cell IDs (generated by `Script8_Armbruster2026_Preparation_for_MapMyCell.Rmd`), as well as the corresponding count matrix with zebrafish gene symbols
converted to their mouse orthologs (generated by `Armbruster2026_MapMyCellInputGeneration.ipynb`), which serves as the input for the MapMyCells analysis.

The files are not included in this repository because of GitHub file size limitations. They can be recreated by running the corresponding R Markdown script and Python notebook.

Expected files: 
- `modified_expression_matrix_zebrafishnames.csv`
- `modified_expression_matrix_mousenames.csv`
