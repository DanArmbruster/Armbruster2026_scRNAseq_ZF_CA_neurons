# MapMyCells_output_data

This folder contains the output files generated by the MapMyCells tool (Allen Institute; RRID:SCR_024672). These files were used for the analyses, visualizations, and supplementary tables generated by `Armbruster2026_MapMyCellOutputAnalysis.ipynb` (Figure 5 and Table S5).
- Direct outputs of MapMyCells: 
  - `own-zebrafish-data_yao-mousebrain-data_HierarchicalMapping.csv`
  - `own-zebrafish-data_yao-mousebrain-data_HierarchicalMapping.json`
  - `own-zebrafish-data_yao-mousebrain-data_HierarchicalMapping_summary_metadata.json`
  - `validation_log.txt`

- Processed output tables generated in "Armbruster2026_MapMyCellOutputAnalysis.ipynb" and presented in Tables S5C and S5D:
  - `mapmycells_unfiltered_results_table.csv`
  - `mapmycells_bootstrap_subclass_filtered_results_table.csv`
