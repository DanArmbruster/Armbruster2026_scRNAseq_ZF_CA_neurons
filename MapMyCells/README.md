# MapMyCells

The files are not included in this repository because they can be reproduced by running the respective R Markdown scripts and Python notebooks. 

After running the corresponding R Markdown scripts and Python notebooks, this folder contains the input and output files used for the MapMyCells workflow (Allen Institute; RRID:SCR_024672). It includes the raw count matrix of the annotated zebrafish CA dataset with 
cluster annotations appended to the cell IDs (generated by "Script8_Armbruster2026_Preparation_for_MapMyCell.Rmd"), as well as the corresponding count matrix with zebrafish gene symbols converted
to their mouse orthologs (generated by "Armbruster2026_MapMyCellInputGeneration.ipynb"), which served as input for the MapMyCells analysis.

The folder also contains the MapMyCells output files that were used for the analyses, visualizations, and supplementary tables generated by "Armbruster2026_MapMyCellOutputAnalysis.ipynb" (Figure 5 and Table S5).

The folder structure is retained to keep the organization of the analysis workflow.
