# OwnData_anndata_file

This folder should contain the AnnData object `own_seurat_annotated.h5ad` generated from the annotated zebrafish CA dataset for downstream Python analyses. 

The AnnData object is not included in this repository because of GitHub file size limitations. It can be recreated by running `Script8_Armbruster2026_Preparation_for_MapMyCell.Rmd`.
