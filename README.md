# Armbruster et al. (2026)
## scRNA-seq reveals zebrafish catecholaminergic neuron subtypes with complex neurotransmitter and neuropeptide profiles

This repository contains the code, intermediate resources, and analysis workflows accompanying Armbruster et al. (2026). It includes all R Markdown scripts and Python notebooks required to reproduce the preprocessing, downstream analyses, figures, and supplementary tables presented in the manuscript.

---

## Repository structure

| Folder | Description |
|--------|-------------|
| **DEG_tables/** | Differential expression tables generated by the analysis scripts that were used to prepare the supplementary tables. |
| **Figures/** | Individual plots generated by the analysis scripts. Several of these plots were assembled into the figures presented in the manuscript. |
| **MapMyCells/** | Input and output files generated during MapMyCells analyses. |
| Mapped_Data/ | Contains the RNA STARsolo (Dobin et al., 2013) mapped sequencing data of 5 dpf zebrafish larva CA cells mapped to a modified GRCz10.91 zebrafish reference genome containing additional EGFP and E2A-QF2 sequences. Due to GitHub file size limitations the mapped data need to be downloaded from the NCBI Gene Expression Omnibus under the accession number GSE337333. |
| **other_data_tables/** | Additional tables generated during the analyses. |
| **OwnData_anndata_file/** | AnnData object generated from the annotated zebrafish CA dataset for downstream Python analyses. |
| **PythonNotebooks/** | Python notebooks used for MapMyCells analyses, cross-species comparisons and generation of Figure 5. |
| **rawcount_csv_of_Figure1c_clusters/** | Raw count table of the annotated data presented in Figure 1C. File not included due to its size but can be recreated running the scripts and downloaded from the NCBI Gene Expression Omnibus under the accession number GSE337333. |
| **RDS_files/** | Intermediate Seurat objects generated during the analysis. These files are not included because of their size but can be recreated by running the analysis scripts. |
| **Resources/** | Additional ressources required for the analyses (e.g. lists of transcription factors, cell cycle genes and neurotransmitter release markers). |
| **RScripts/** | R Markdown scripts used for all preprocessing and data analysis steps, required to generate figures and tables of the manuscript. |

## R Scripts Descriptions

| R Script | Description |
|--------|-------------|
| **Script1_Armbruster2026_QC-Filtering.Rmd** | Loads the mapped 10X Genomics dataset, converts it into a Seurat object and performs quality control and filtering prior to downstream analyses. |
| **Script2_Armbruster2026_DoubletRemoval.Rmd** | Identifies and removes potential doublets from the filtered Seurat object using the DoubletFinder workflow. |
| **Script3_Armbruster2026_NormalizationClusteringAnnotation.Rmd** | Performs normalization, cell cycle correction, dimensionality reduction, clustering, and annotation of the quality-controlled dataset. Then it identifies differentially expressed genes and transcription factors and characterizes the neurotransmitter and neuropeptide production and reception signatures across clusters. This script generates the visualizations presented in Figures 1, 6, and S2 together with the associated supplementary tables. |
| **Script4_Armbruster2026_RajOwn_TFcodes.Rmd** | Compares CA cluster transcription factor expression with a published zebrafish whole-brain reference dataset published by Raj et al. (2020) (see below under **External datasets and large data files**), identifies cluster-enriched transcription factors and generates the heatmap shown in Figure 2A and the associated supplementary tables. |
| **Script5_Armbruster2026_PandeyIntegration_QC-Filtering.Rmd** | Performs quality control, preprocessing, and integration of the annotated CA dataset with the published zebrafish telencephalon scRNA-seq dataset published by Pandey et al. (2023) (see below under **Public data**). |
| **Script6_Armbruster2026_PandeyIntegration_IntegrationClusteringAnnotation.Rmd** | Performs integration, clustering and annotation of the combined CA and published zebrafish telencephalon datasets, identifies differentially expressed genes and transcription factors and characterizes the neurotransmitter and neuropeptide signaling signatures across clusters. This script generates visualizations presented in Figures 1, 6 and S2 as well as accompanying supplementary tables. |
| **Script7_Armbruster2026_RajPandeyOwn_TFcodes.Rmd** | Compares transcription factor expression in the integrated CA dataset generated in Script 6 with a published zebrafish whole-brain reference dataset published by Raj et al. (2020) (see below under **External datasets and large data files**), identifies cluster-enriched transcription factors and generates the heatmap shown in Figure 2D together with the associated supplementary tables. |
| **Script8_Armbruster2026_Preparation_for_MapMyCell.Rmd** | Exports the annotated zebrafish CA count matrix for MapMyCells analysis and converts the Seurat object into AnnData format for the cross-species analyses shown in Figure 5. |
| **Script9_Armbruster2026_HindbrainSubset.Rmd** | Performs subclustering and annotation of the hindbrain clusters (Hb1–Hb3), identifies cluster-enriched transcription factors and characterizes rostro-caudal identity based on Hox gene expression. This script generates the visualizations presented in Figure 3 and Figure S3 together with the accompanying supplementary tables. |
| **Script10_Armbruster2026_PeripheralSubset.Rmd** | Performs subclustering, annotation and differential expression analysis of the neuroepithelial (NEC) as well as peripheral neuron (PN) clusters and generates the visualizations presented in Figure 4 together with the accompanying supplementary tables. |
| **Script11_Armbruster2026_Kamath_MesdiDANeurons.Rmd** | Downloads and reconstructs the published human substantia nigra pars compacta (A9) dopaminergic neuron scRNA-seq dataset (Kamath et al., 2022) and  characterizes the neurotransmitter and neuropeptide signaling signatures across clusters. |

## Python Notebooks Descriptions

| Python Notebook | Description |
|--------|-------------|
| **Armbruster2026_MapMyCellInputGeneration.ipynb** | Loads annotated zebrafish CA count matrix, converts zebrafish gene names to their corresponding mouse orthologs and exports the renamed expression matrix for MapMyCells analysis. |
| **Armbruster2026_MapMyCellOutputAnalysis.ipynb** | Analyzes the MapMyCells output, exports filtered and unfiltered cell assignment tables (Tables S5C and S5D) and generates the visualization shown in Figure 5A. |
| **Armbruster2026_YaoWMBAnalysis.ipynb** | Downloads a subset of the Allen Institute Whole Mouse Brain (WMB) dataset (see below under **External datasets and large data files**), prepares an AnnData object for  analysis and compares marker gene expression between selected zebrafish CA clusters and their corresponding MapMyCells-assigned mouse brain subclasses shown in Figure 5. |

| 6 dpf to adult whole telencephalon scRNA-seq  data | Pandey et al., 2023 (10.1101/gr.277278.122) | GEO GSE212314 |
