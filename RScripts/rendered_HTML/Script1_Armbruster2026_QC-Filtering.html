Script1_Armbruster2026_QC-Filtering

Daniel Armbruster

2026-07-24

  • In this script we loaded the mapped 10X Genomics data, converted it into a Seurat object, performed quality control, and filtered the dataset to retain cells with at least 500 expressed genes per cell, less than 8% mitochondrial content per cell, and positive GFP expression.

  • The session info including the used packages and their versions is provided at the end of this script.

1. Load Packages

library(SingleCellExperiment)
library(Seurat)
library(dplyr)
library(ggplot2)

2 Load Data and Generate Seurat Object

# Load mapped output files into a sparse count matrix
allcells_sparse <- Read10X(data.dir = "Mapped_Data/")

# Generate Seurat object with an initial filtering for cells expressing > 200 genes
allcells <- CreateSeuratObject(allcells_sparse, min.features = 200)

3 Quality Control

3.1 Prepare Metadata for QC

# Calculate log10-transformed genes per UMI ratio
allcells$log10GenesPerUMI <- log10(allcells$nFeature_RNA) / log10(allcells$nCount_RNA)

3.2 Add further info to metadata

  • Store EGFP and MT content per cells in metadata
# Add EGFP gene expression percentage
allcells$EGFPratio <- PercentageFeatureSet(object = allcells, pattern = "EGFP")

# Add mitochondrial gene expression percentage
allcells$MTratio <- PercentageFeatureSet(object = allcells, pattern = "mt-*")

# Add cell IDs to metadata
allcells$cells <- rownames(allcells@meta.data)

#Create a sample colum
allcells$sample <- "GFP+_sort"

# Rename metadata columns 
allcells@meta.data <- allcells@meta.data %>% dplyr::rename(seq_folder = orig.ident, nUMI = nCount_RNA, nGene = nFeature_RNA)
# Save unfiltered Seurat object 
save(allcells, file="RDS_files/Script1_Armbruster2026_unfiltered.rds")
# Extract metadata for QC
metadata <- allcells@meta.data

4 Filtering

4.1 Cell level filtering

  • Filtering thresholds:

    • nGene >500

    • Mtratio < 8 (only cells with less then 8 % mitochondrial reads)

    • Positive for EGFP expression

filtered_cells <- subset(x = allcells, subset = (nGene >=500 & MTratio < 8 & EGFPratio > 0))

4.2 Gene level filtering

  • Will remove genes that are expressed in less than 5 cells
print(paste("Gene number before:", length(rownames(filtered_cells))))
## [1] "Gene number before: 34322"
# Only keep genes expressed in at least 5 cells
counts <- GetAssayData(object = filtered_cells, slot = "counts")
## Warning: The `slot` argument of `GetAssayData()` is deprecated as of SeuratObject 5.0.0.
## ℹ Please use the `layer` argument instead.
## This warning is displayed once per session.
## Call `lifecycle::last_lifecycle_warnings()` to see where this warning was
## generated.
nonzero <- counts > 0
keep_genes <- Matrix::rowSums(nonzero) >=5
filtered_counts <- counts[keep_genes,]
filtered_cells <- CreateSeuratObject(filtered_counts, meta.data = filtered_cells@meta.data)

print(paste("Gene number after:", length(rownames(filtered_cells))))
## [1] "Gene number after: 20019"
