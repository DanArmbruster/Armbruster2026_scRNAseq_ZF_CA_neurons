# Kamath2022

This folder contains files required to reconstruct and analyze the published human substantia nigra pars compacta (A9) dopaminergic neuron scRNA-seq dataset from Kamath et al. (2022).

The required data files are not included in this repository because of GitHub file size limitations.

After downloading the dataset from the Broad Institute Single Cell Portal (SCP1768), place the following files in this folder:

| Required filename | Original download filename |
|-------------------|----------------------------|
| `barcodes.tsv.gz` | `Homo_bcd.tsv.gz` |
| `features.tsv.gz` | `Homo_features.tsv.gz` |
| `matrix.mtx.gz` | `Homo_matrix.mtx.gz` |
| `da_UMAP.tsv` | `da_UMAP.tsv` |
| `METADATA_PD.tsv` | `METADATA_PD.tsv` |
