# Pandey2023_mapped

This folder contains the mapped scRNA-seq data from the zebrafish telencephalon dataset published by Pandey et al. (2023) that are required for the integration analyses in **Armbruster et al. (2026)**.

The mapped data are not included in this repository because of GitHub file size limitations.

Download the mapped barcode, feature, and matrix files for all samples from the NCBI Gene Expression Omnibus (GEO) **GSE212314** and place them in subdirectories for each sample (e.g. `6dpf_b1`, `6dpf_b2`, ..., `Adult_b2_2`), each containing:

- `barcodes.tsv.gz`
- `features.tsv.gz`
- `matrix.mtx.gz`
