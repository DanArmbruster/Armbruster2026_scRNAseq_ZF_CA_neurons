# Resources

This folder contains additional resource files required for the analyses presented in **Armbruster et al. (2026)**.

Some large resource files (see the subdirectories `Kamath2022`, `Pandey2023_mapped`, and `Raj2020_5dpf`) are not included in this repository due to GitHub file size limitations. These datasets were originally published by other authors and can be downloaded separately as described in the corresponding subdirectories.
