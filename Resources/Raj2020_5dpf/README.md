# Raj2020_5dpf

This folder contains the published 5 dpf zebrafish whole-brain scRNA-seq dataset from Raj et al. (2020) required for the analyses in **Armbruster et al. (2026)**.

The dataset is not included in this folder because of GitHub file size limitations.

Download the following file from the NCBI Gene Expression Omnibus (GEO) **GSE158142** and place it in this folder:

- `GSE158142_zf5dpf_cc_filt.cluster.rds`
