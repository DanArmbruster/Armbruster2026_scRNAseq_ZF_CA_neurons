# other_data_tables

This folder contains additional data tables generated during the analyses.

The following Excel files were created in `Script3_Armbruster2026_NormalizationClusteringAnnotation.Rmd` and `Script6_Armbruster2026_PandeyIntegration_IntegrationClusteringAnnotation.Rmd`. They contain the average normalized transcription factor expression for the clusters shown in Figures 1C and 1E. Modified and formatted versions of these tables are included in Supplementary Table S1 of the manuscript.

- `Script3_Figure1c_clusters_avgnormalizedTFcounts.xlsx`
- `Script6_Figure1e_clusters_avgnormalizedTFcounts.xlsx`
